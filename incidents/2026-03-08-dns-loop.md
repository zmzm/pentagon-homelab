# Incident: DNS loop in Pi-hole

Date:
2026-03-08

Severity:
High

## Summary
DNS traffic spiked due to recursive DNS loop between Pi-hole and Tailscale MagicDNS.

## Impact
Pi-hole became unhealthy.
Internet access degraded temporarily.

## Root Cause
Conditional forwarding caused DNS queries to be sent to MagicDNS.
Tailscale DNS override redirected queries back to Pi-hole.

Resulting in recursive loop.

## Resolution
Disabled conditional forwarding in Pi-hole.

## Prevention
Use Unbound as the only upstream resolver.
Avoid forwarding when using Tailscale DNS override.

## Notes
Peak load reached ~8000 DNS queries in 10 minutes.
